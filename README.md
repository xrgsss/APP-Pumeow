# Deskripsi Project
APP-Pumeow adalah aplikasi yang dikembangkan untuk memberikan pengalaman interaksi yang mudah dan efisien bagi pengguna. Aplikasi ini dirancang dengan fokus pada kemudahan penggunaan, performa yang stabil, serta tampilan yang user-friendly.

Project ini dibuat sebagai bagian dari tugas Daily Project 6 dengan penekanan pada implementasi dan pengujian kualitas aplikasi.

# Tujuan Pengujian
Pengujian dilakukan untuk memastikan bahwa aplikasi memenuhi aspek kualitas yang telah ditentukan pada tahap desain, meliputi:

- Functionality
- Usability
- Performance
